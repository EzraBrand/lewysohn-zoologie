Ludwig Lewysohn, Die Zoologie des Talmuds

Frankfurt am Main, 1858: the first systematic collection of the Talmudic and Midrashic material on animals, in German (set in Fraktur) with Hebrew, Aramaic, Greek and Latin. This is a test reading edition: machine transcription and English translation of a few pages, made to see what current tools can do. The companion project for plants is Löw, Die Flora der Juden.

What this is, and what it is not

  • The transcription and the translation are machine output (Claude Opus 5.5). Two pages (pp. 68 and 70) were checked by hand.
  • The book has no list of abbreviations. They are expanded from a table built from the text and reviewed by hand (table); “guess” marks an expansion that is not certain.
  • Each page links to the scan: please check it before citing anything.
  • Code, data, method and costs: github.com/EzraBrand/lewysohn-zoologie.
